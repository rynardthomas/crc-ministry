# CRC Ministry — home-screen app (launcher)

This small site gives the CRC Ministry app a proper icon and opens it full-screen (no browser bar) from the phone's home screen.

Live at **https://rynardthomas.github.io/crc-ministry/**

## Add it to your phone
- **iPhone (Safari):** open the link → Share → *Add to Home Screen*
- **Android (Chrome):** open the link → ⋮ menu → *Install app* / *Add to Home screen*

## Notes
- `index.html` points at the live app link (`APP_URL` at the top). If that link ever changes, edit it here.
- The first time someone opens the home-screen version they sign in once more (phones keep it separate from the browser).
- QR check-in links keep working as before; they don't need this page.
